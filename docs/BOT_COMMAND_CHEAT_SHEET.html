What each start script does

  1. npm run bot:stop
  2. node scripts/ensure-redis.mjs
  3. npm run build
  4. node scripts/preflight-event-purity-env.mjs (event-purity only)
  5. scripts/launcher-run-bot-detached.sh — detached nohup bot
